## 1. 产品概述

### 1.1 产品定位
面向个人的私有笔记管理系统，提供类印象笔记的核心笔记管理能力。V0.1 聚焦最基础的笔记 CRUD、笔记本分类、标签管理、双向链接和回收站功能，为 V0.2 的知识图谱和智能问答奠定数据基础。

### 1.2 核心价值
- 结构化笔记管理：笔记本 + 标签双维度组织
- Markdown 编辑：完整 Markdown 语法支持
- 笔记互链：通过 `[[笔记标题]]` 建立笔记间双向引用
- 安全删除：软删除回收站机制，防止误删

### 1.3 不做的事（V0.1 边界外）
- 不做图谱可视化
- 不做向量检索和智能问答
- 不做图片上传
- 不做全文搜索（ES 暂未集成）
- 不做 LLM 实体抽取
- graph/vector/knowledgeqa 模块仅创建空包占位

### 1.4 V0.1.5 新增：文档解析（2026-08-10 更新）
- 上传 PDF/Word 文档，调用 DeepSeek API 解析章节/小节结构
- 文档绑定笔记本，解析结果可手动编辑
- 章节/小节可绑定为笔记本中的笔记
- 支持一键生成思维导图笔记（LLM 生成 Markdown 层级结构）
- PDF/Word 预览面板可切换显示/隐藏，支持选中复制文字

### 1.5 V0.2 新增：章节独立绑定 + 知识点导航（2026-08-11 更新）
- 章节从 JSON 树拆分为独立 `document_chapter` 表，每个章节有唯一主键，支持 `pageStart/pageEnd` 页码元数据
- 章节与笔记一对一绑定：一个章节只能绑定一个笔记，一个笔记最多对应一个章节
- 笔记编辑页分栏布局：打开已绑定章节的笔记，自动切左右分栏（左导图/编辑、右PDF预览），默认跳到章节起始页，有开关可隐藏PDF面板，中间分隔条可拖拽调比例（30%-80%）
- **知识点导航核心**：脑图节点 ↔ PDF页码范围双向映射。用户在导图节点上可手动建立与PDF某页/几页的关联，节点显示 📖 角标，点击跳PDF；顶部「🗺️ 知识点导航」抽屉列出所有已关联节点（标题+页码+摘录），支持搜索、跳页、反查定位脑图节点、编辑、删除。

## 4. 业务流程

### 4.1 笔记创建流程

```
用户点击"新建笔记"
    → 弹出创建对话框：输入标题、选择笔记本、选择标签
    → 前端 POST /api/note/save { title, notebookId, tagIds }
    → 后端校验：标题非空(≤256)、notebookId 存在
    → 写入 note 表，计算 word_count
    → 写入 note_tag_rel 表
    → 解析 content 中的 [[xxx]]，匹配 note 表标题，写入 note_inner_link
    → 返回笔记详情（含 id）
    → 前端打开笔记编辑页面
```

### 4.2 笔记保存流程（编辑内容）

```
用户在编辑器修改 Markdown 内容
    → 手动保存或自动保存触发
    → 前端 POST /api/note/save { id, title, content, tagIds }
    → 后端：
        1. 更新 note 表（title, content, word_count, updated_at）
        2. 删除旧 note_tag_rel，批量写入新关联
        3. 删除旧 note_inner_link（WHERE source_note_id = id），重新解析 [[xxx]] 写入
        4. 同步返回成功
    → 前端显示保存成功提示
```

### 4.3 笔记删除与恢复流程

```
用户删除笔记
    → 前端 DELETE /api/note/{id}
    → 后端设置 is_deleted=1, deleted_at=NOW()
    → 笔记从列表中移除，出现在回收站

用户在回收站恢复笔记
    → 前端 POST /api/note/{id}/recover
    → 后端设置 is_deleted=0, deleted_at=NULL
    → 笔记回到原笔记本

用户在回收站永久删除
    → 前端 DELETE /api/note/{id}/permanent
    → 后端：删除 note、note_tag_rel、note_inner_link 相关记录
    → V0.1 无需清理图和向量（尚未接入）
```

### 4.4 双向链接解析流程

```
笔记保存触发 innerlink 解析
    → MarkdownParseUtil.scan(content)
    → 正则提取所有 [[xxx]] 中的标题文本
    → 对每个标题：
        1. SELECT id FROM note WHERE title = 'xxx' AND is_deleted = 0
        2. 如果找到：INSERT/IGNORE note_inner_link(source_note_id, target_note_id, target_title)
        3. 如果未找到：跳过（目标笔记不存在）
    → 可选：返回未匹配的标题列表，前端提示"以下链接目标不存在"
```

### 4.5 笔记本删除校验流程

```
用户删除笔记本
    → 前端 DELETE /api/notebook/{id}
    → 后端校验：
        1. 是否有子笔记本：SELECT COUNT(*) FROM notebook WHERE parent_id = {id}
        2. 是否有笔记（含回收站）：SELECT COUNT(*) FROM note WHERE notebook_id = {id}
    → 如果任一 > 0：返回错误 "笔记本非空，无法删除"
    → 如果都 = 0：执行删除
```

## 5. 页面设计

### 5.1 整体布局（三栏结构）

```
┌──────────────────────────────────────────────────────────┐
│  TopBar: 系统标题                  [全局搜索] [设置]      │
├──────────┬───────────────────────────────┬────────────────┤
│          │                               │                │
│  笔记本树 │       笔记编辑/预览区          │   笔记详情侧栏  │
│          │       (Markdown Editor)        │   - 属性       │
│  📁 全部  │                               │   - 标签       │
│  📁 笔记本A│                               │   - 双向链接   │
│    📁 子B  │                               │   - Stats      │
│  ⭐ 收藏  │                               │                │
│  🗑 回收站 │                               │                │
│          │                               │                │
├──────────┴───────────────────────────────┴────────────────┤
│  StatusBar: 字数 0 | 自动保存 OK                          │
└──────────────────────────────────────────────────────────┘
```

**三栏说明**：
- **左栏 (260px)**：笔记本树 + 快速入口（收藏、回收站），可折叠
- **中栏 (自适应)**：Markdown 编辑器，支持编辑/预览/分屏切换
- **右栏 (280px)**：笔记属性面板，可折叠

### 5.2 页面清单

#### 5.2.1 首页 (Home.vue)

**路由**：`/`

**组件构成**：
- `NotebookTree` — 左栏笔记本树
- `NoteEditor` — 中栏编辑器（初始显示空白引导状态）

**交互**：
- 点击笔记本 → 展开笔记列表（替换中栏为笔记列表）
- 点击笔记 → 中栏切换为编辑器加载该笔记
- 新建笔记按钮 → 弹出创建对话框

**初始引导状态**：
- 当无任何笔记时，中栏显示：
  - "欢迎使用知识笔记"
  - [新建第一篇文章] 按钮

#### 5.2.2 笔记编辑页 (NoteEdit.vue)

**路由**：`/note/:noteId`

**组件构成**：
- 同 Home，但中栏直接加载指定 noteId
- 新增底部状态栏：字数、自动保存状态

**编辑器功能栏**：
```
[B] [I] [H1] [H2] [H3] [• List] [1. List] [""] [[]] [🔗] [🖼] | [✏编辑] [👁预览] [◫分屏]
```

**[[链接提示]**：
- 输入 `[[` 时弹出搜索下拉框
- 实时搜索已有笔记标题
- 选择后自动补全为 `[[笔记标题]]`

**保存机制**：
- 手动保存：Ctrl+S 或点击保存按钮
- 自动保存：停止输入 3 秒后自动保存
- 切换笔记时自动保存当前笔记
- 保存成功后状态栏短暂显示"已保存"

#### 5.2.3 回收站页 (RecycleBin.vue)

**路由**：`/recycle`

**组件构成**：
- 左栏：笔记本树（保持在位）
- 中栏：笔记列表（已删除笔记） + 操作栏

**列表列**：
| 标题 | 原笔记本 | 删除时间 | 操作 |
|------|---------|----------|------|
| 笔记标题 | 笔记本名 | 2026-08-10 | [恢复] [永久删除] |

**交互**：
- 点击标题 → 查看（只读模式，不可编辑）
- [恢复] → 确认弹窗 → 恢复到原笔记本
- [永久删除] → 二次确认弹窗 → 永久删除
- 空状态提示："回收站为空"

**批量操作**：
- 支持全选/多选
- [批量恢复] [批量永久删除]

#### 5.2.4 收藏视图

**路由**：`/favorites` 或在笔记本树中 `⭐ 收藏` 入口

**组件构成**：
- 中栏显示所有收藏笔记列表

**列表展示**：
| 标题 | 笔记本 | 更新时间 | 操作 |
|------|--------|----------|------|
| 笔记标题 | 笔记本名 | 2026-08-10 | [取消收藏] [打开] |

## 6. 数据校验规则

### 6.1 笔记本

| 字段 | 规则 |
|------|------|
| name | 必填，1~128 字符，不允许纯空格 |
| parent_id | 可选，0 表示根级。若指定：必须存在于 notebook 表，且不能为自己的子孙节点（防止循环嵌套） |

### 6.2 笔记

| 字段 | 规则 |
|------|------|
| title | 必填，1~256 字符，不允许纯空格 |
| content | 可选，Markdown 文本，无长度硬限制 |
| notebook_id | 必填，必须存在于 notebook 表 |
| tagIds (API) | 可选，数组，每个 ID 必须存在于 tag 表 |

### 6.3 标签

| 字段 | 规则 |
|------|------|
| name | 必填，1~64 字符，唯一（不区分中英文） |
| color | 可选，hex 颜色值（如 #ff0000），无输入时生成随机颜色 |

### 6.4 双向链接

| 字段 | 规则 |
|------|------|
| source_note_id | 必填，必须存在 |
| target_note_id | 必填，必须存在，不能等于 source_note_id（禁止自引用） |
| target_title | 必填，提取自 [[xxx]] 原文 |

### 6.5 公共规则

- 所有列表接口默认分页：page ≥ 1，size 范围 [1, 100]
- 时间格式统一：`yyyy-MM-dd HH:mm:ss`
- 空字符串 "" 和 null 视为等价，统一处理为 null

## 9. 异常场景处理

| 场景 | 前端行为 | 后端行为 |
|------|---------|---------|
| 网络断开 | Toast "网络连接失败，请检查网络" | - |
| 接口超时 | 前端设置 30s 超时，提示超时重试 | - |
| 保存笔记时 title 为空 | 前端校验拦截，红字提示 | 返回 400 + msg |
| 删除非空笔记本 | - | 返回 409 + "笔记本非空，无法删除" |
| [[链接]]目标不存在 | 保存成功，前端可提示"链接目标未找到" | 解析时跳过不存在的标题 |
| 同名笔记本 | 允许（通过 ID 区分），不做唯一约束 | - |
| 同名标签 | 不允许 | 返回 409 + "标签名已存在" |
| 并发编辑同一笔记 | V0.1 不做乐观锁，后保存覆盖先保存 | - |
| 数据库连接失败 | - | 返回 500 + "服务内部错误" |

### 4.6 文档解析与脑图生成流程（V0.1.5）

```
用户上传 PDF/Word
    → 选择目标笔记本
    → 前端 POST /api/document/upload (multipart/form-data)
    → 后端：
        1. 保存文件到 uploads/ 目录
        2. 提取文档全文文本（PDFBox/POI）
        3. 调用 DeepSeek Flash API 解析章节结构
        4. 写入 document_section 表
        5. 返回解析结果（JSON 树形结构）
    → 前端展示章节列表，支持编辑

用户点击"生成脑图"
    → 前端 POST /api/document/{id}/generate-mindmap { sectionIndex }
    → 后端调用 DeepSeek API 为指定小节生成 Markdown 脑图
    → 创建笔记（title=章节名, content=生成的Markdown）
    → 返回 noteId
    → 前端打开新笔记编辑/脑图模式

用户打开笔记编辑/脑图
    → 如果笔记所属笔记本有绑定文档，显示"📄 文档"按钮
    → 点击按钮 → 在页面另一侧展示 PDF/Word 预览面板
    → 可再次点击隐藏面板
```

### 4.7 章节绑定 + PDF对照 + 知识点导航流程（V0.2）

```
【阶段1：上传解析 + 章节绑定】
用户上传 PDF/Word → 后端解析 + 拆分写入 document_chapter 独立表
    → 文档面板章节树显示：每节带 [P.x~y] 页码标识 + 绑定状态
    → 用户操作章节：
        • 🔗绑定笔记：弹Dialog选择本笔记本下已有笔记 → PUT /document/chapter/{id}/bind-note
        • ➕新建绑定：先创建空白笔记（标题=章节名），再自动bind
        • 🧠生成脑图+自动绑定：调LLM生成Markdown脑图，创建笔记后自动bind（一步到位）
        • 🔄重新绑定 / ✂️解绑

【阶段2：打开笔记 → 自动分栏】
用户打开已绑定章节的笔记
    → GET /api/note/{id} 返回 bindInfo{documentId, chapterId, chapterTitle, pageStart, pageEnd}
    → 顶部显示 [📑 原文对照 ON / OFF]（默认ON）+ [🗺️ 知识点导航]
    → 页面左右分栏：
        • 左：笔记编辑 / 导图容器
        • 右：<iframe src="/api/document/{id}/preview#page={pageStart}">
    → 中间分隔条：鼠标拖拽调整比例（30%~80%）
    → PDF工具条：[◀上一页] [P.__ 跳转] [▶下一页]

【阶段3：知识点关联】
用户在导图模式下，选中某节点 → 点击悬浮🔖按钮
    → 弹出关联对话框：[起始页] [结束页] [原文摘录]
    → 快捷：如果右栏PDF正打开到对应页，可用「📌取当前PDF显示页」一键填充
    → 保存 → POST /note-pdf-ref/save 写入 note_pdf_ref 表（noteId+nodeUid唯一）
    → 导图节点右上角渲染 📖 角标
    → 点击 📖 角标 → emit jumpPdfPage → 右栏iframe改 #page={pageStart} 自动跳转

【阶段4：知识点导航抽屉】
用户点击顶部 [🗺️ 知识点导航]
    → 右侧拉出抽屉：标题 + 搜索框 + 关联列表
    → 搜索：前端本地过滤 nodeTitle / excerpt
    → 列表条目：[📖 P.18-20] {nodeTitle}
    → 点击条目 → ①PDF开启则跳页 ②导图模式下center定位该节点
    → 条目右侧 ✏️编辑关联 → 打开🔖对话框回填
    → 条目右侧 🗑️删除关联 → DELETE /note-pdf-ref/{id}
```
